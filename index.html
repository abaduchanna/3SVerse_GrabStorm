GrabStorm — the multi-segment download accelerator for Windows

Free and open source. GrabStorm moves files over HTTP(S) with up to 32 parallel connections, keeps per-download state so nothing is lost when you pause or close the app, and integrates silently with every major browser — the browser hands the file to GrabStorm and it takes it from there.

  • Up to 32 parallel segments per download — faster on slow or high-latency links
  • Pause, resume and close safely — per-download state is persisted
  • Silent browser integration: Chrome, Edge, Brave, Firefox, Opera, Vivaldi
  • No dialogs, no bloat, no tracking — MIT licensed, clean-room implementation
  • Works on Windows 10 and Windows 11
